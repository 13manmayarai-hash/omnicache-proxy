Architecture & Superpowers

Built For Serious AI Engineers

⚡

Zero SDK Rewrite

Change just one string: point base_url to OmniCache. Works out-of-the-box with official openai, anthropic, LangChain, and LlamaIndex libraries.

🧠

Local Quantized Embeddings

Embedding models run right inside the proxy binary. Zero external network calls to calculate prompt similarity vectors. Fast, private, zero added cost.

🤖

Model Context Protocol

First-class MCP JSON-RPC 2.0 streaming server. RFC 6749 and RFC 7636 PKCE compliant for Claude Connectors Directory, Claude Desktop, and Cursor.

📉

Model Cascading

Intelligently evaluates query complexity. Automatically delegates simple factual requests to fast, cheap models (e.g. gpt-4o-mini) while routing complex reasoning to o3 or claude-3-7-sonnet.

🌐

Distributed CRDT Edge Mesh

Multi-node peer mesh syncs cache states and vector embeddings over encrypted HTTP/2 gossip with Hybrid Logical Clocks (HLC) and conflict-free data types.

🛡️

Enterprise Virtual Keys

Assign virtual API keys to teams, apps, or subagents. Enforce monthly dollar budget caps and per-minute rate limits atomically with zero race conditions.

10-Second Setup

Drop-In Integration

from openai import OpenAI

# 1. Point base_url to your OmniCache proxy
client = OpenAI(
    base_url="https://omnicache.rawwgrid.com/v1",
    api_key="omni_live_your_virtual_key"  # or upstream OPENAI_API_KEY
)

# 2. Make requests as normal — semantic vector caching is automatic!
response = client.chat.completions.create(
    model="gpt-4o",
    messages=[{"role": "user", "content": "Explain vector indexing in 3 bullet points"}]
)

print(response.choices[0].message.content)
